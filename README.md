# AI Discord Bot

A free AI-powered Discord bot with multiple features.

## Features
- `!ask` or `/ask` - Ask the AI anything
- `!code` or `/code` - Get help with coding
- `!summarize` or `/summarize` - Summarize text
- `!translate` or `/translate` - Translate to other languages
- Mention the bot to get a response

## Setup

1. Clone this repo
2. Install dependencies: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and add your tokens
4. Run: `python bot.py`

## Environment Variables

- `DISCORD_TOKEN` - Your Discord bot token
- `HF_API_KEY` - Your Hugging Face API key (free at huggingface.co)

## Deploy to Railway

1. Fork this repo to GitHub
2. Go to railway.app
3. Create new project from GitHub repo
4. Add environment variables
5. Deploy!
